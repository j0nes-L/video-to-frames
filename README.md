# Convert into frames

Right-click any video in Windows Explorer, choose **Convert into frames**, and a dialog lets you pick
frame rate, start/end time and output folder before ffmpeg extracts the images.

## Install

1. Double-click **Setup.cmd**.
2. If ffmpeg is missing, click **Install ffmpeg** (downloads Gyan.FFmpeg via winget) or
   **Select manually** if you already have an ffmpeg.exe somewhere.
3. Pick the file types you want and click **Add to right-click menu**.

Everything is written to `HKCU\Software\Classes\SystemFileAssociations`, so no admin rights are
needed and nothing changes for other user accounts.

On **Windows 11** the entry lives in the classic context menu: open **Show more options**, or hold
**Shift** while right-clicking.

To undo, run Setup.cmd again and click **Remove**.

## Dialog

| Field | Meaning |
| --- | --- |
| Start / End | `hh:mm:ss.ms`, `mm:ss` or plain seconds. The end defaults to the full video length and is clamped to it. |
| Frames per second | How many images per second of video, e.g. `1` gives one image per second, `0.5` one every two seconds. |
| Every frame of the source | No resampling, one image per source frame. |
| Fixed number of frames | Spreads the given number of images evenly over the selected time range. Useful for photogrammetry. |
| Folder | Defaults to the folder the video sits in. Optionally a `<videoname>_frames` subfolder. |
| Format | JPG with a quality value (1 = best, 31 = smallest) or PNG. |
| Width | Resizes with the lanczos filter, keeping the aspect ratio. `0` keeps the original size. |
| Prefix | File names become `<prefix>00001.jpg`, `<prefix>00002.jpg`, ... |

The estimated frame count updates live, and the progress bar reflects ffmpeg's real progress.
**Start** turns into **Cancel** while a conversion is running.

## Files

| File | Purpose |
| --- | --- |
| `ConvertToFrames.ps1` | The dialog and the conversion itself. |
| `Setup.ps1` / `Setup.cmd` | Setup window: ffmpeg check, file type selection, install/remove. |
| `ConvertToFramesLauncher.exe` | Generated by Setup. Starts the dialog without a console window flashing. |
| `ConvertToFrames.ico` | Generated by Setup. Icon for the menu entry and the window. |
| `config.json` | Created only when you pick an ffmpeg.exe manually. |

Keep this folder where it is. The context menu stores absolute paths, so moving or renaming the
folder breaks the entry until you run Setup again.

## Adding more file types

Edit the `$Extensions` list at the top of `Setup.ps1`, then run Setup and click
**Add to right-click menu** again.

## Standalone use

`ConvertToFramesLauncher.exe` also works without an argument or a context menu entry: it opens a file
picker first. It can be pinned to the taskbar or dropped into the Start menu.
